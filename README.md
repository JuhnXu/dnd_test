# DND HTML5 战棋 Demo v18.2.3

本版本基于 v18.2.1，新增 **重复点击确认** 操作识别，减少游玩时对确认按钮的依赖。

## 页面入口

- `index.html`：纯游玩界面，不显示 Debug / 编辑工具。
- `editor.html`：数据编辑器，包含地图、出生点、单位属性、导入、保存、校验和导出功能。


## v18.2.3 新增

1. 重复点击确认
   - 移动：第一次点击目的地进入确认，第二次点击同一目的地直接执行移动。
   - 普通攻击：第一次点击目标进入确认，第二次点击同一目标直接攻击。
   - 单体技能 / 法术：第一次点击目标进入确认，第二次点击同一目标直接释放。
   - AOE 技能 / 法术：第一次点击范围中心进入确认，第二次点击同一格直接释放。

2. 确认提示优化
   - 确认面板文案会提示“再次点击目标/目的地可直接确认”。
   - 原有“确认 / 取消”按钮保留，适合不想误操作时使用。

## v18.2 新增

1. 编辑器与游玩界面分离
   - 游玩界面只保留战斗 UI。
   - 编辑器独立在 `editor.html`。

2. JSON 导入
   - 支持导入 `levels.json`
   - 支持导入 `units.json`
   - 支持导入 `skills.json`
   - 支持导入 `spells.json`
   - 支持导入 `classFeatures.json`
   - 支持导入完整项目数据包

3. 本地保存
   - 可保存当前编辑结果到浏览器 `localStorage`
   - 刷新后自动读取本地保存
   - 可清除本地保存，恢复 data 目录默认数据

4. 数据校验
   - 检查出生点重叠
   - 检查出生点是否在障碍物上
   - 检查出生点是否越界
   - 检查单位 ID 是否存在
   - 检查技能 / 法术 / 职业特性引用是否存在

5. 完整数据包导出
   - 导出 `levels`
   - 导出 `units`
   - 导出 `skills`
   - 导出 `spells`
   - 导出 `classFeatures`

## 运行方式

```bash
cd dnd-html5-demo-v18-2-2
python -m http.server 8000
```

游玩界面：

```text
http://localhost:8000
```

编辑器界面：

```text
http://localhost:8000/editor.html
```

## 注意

浏览器本地保存只保存在当前浏览器和当前域名下。要永久纳入项目文件，需要下载导出的 JSON，并替换 `data/` 目录内的对应文件。
