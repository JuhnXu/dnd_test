# DND HTML5 战棋 Demo v8

本版本基于 v7.1，重点优化战斗可读性和交互体验。

## 新增内容

1. 棋盘血条
   - 每个单位头像下方显示血条和 HP 数字。

2. 状态图标
   - 防御、中毒、Buff 等状态会在棋盘头像旁显示小图标。
   - 单位列表也会显示状态标签。

3. 目标高亮
   - 普通攻击 / 敌方技能：红色描边。
   - 治疗 / Buff 友军技能：绿色描边。
   - AOE 技能：橙色区域提示。

4. 技能说明
   - 技能卡显示目标、范围、伤害/治疗、冷却、剩余次数。
   - 鼠标悬停技能卡会显示更完整说明。

5. 战斗日志颜色
   - 命中、未命中、治疗、Buff、豁免、持续伤害、回合切换使用不同颜色。

6. 回合流程提示
   - 棋盘上方显示当前单位、当前模式、剩余移动和动作状态。

## 运行方式

```bash
cd dnd-html5-demo-v8
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

## 说明

项目使用 ES Module，因此建议通过本地服务器运行，不要直接双击 index.html。
