# DND HTML5 战棋 Demo v10

本版本基于 v9 继续开发，新增“法术系统雏形”。

## 运行方式

```bash
cd dnd-html5-demo-v10
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

## v10 新增内容

1. 法术数据配置化
   - 新增 `data/spells.json`
   - 法术会和技能一起进入技能栏

2. 施法属性系统
   - 单位新增 `spellcastingAbility`
   - 法术攻击 = 熟练加值 + 施法属性修正
   - 法术 DC = 8 + 熟练加值 + 施法属性修正

3. 法术位系统
   - 单位新增 `spellSlots`
   - 1 环及以上法术会消耗法术位
   - 戏法不消耗法术位

4. 新增玩家法术
   - 火焰箭：戏法，远程法术攻击
   - 治疗真言：1 环治疗法术
   - 燃烧之手：1 环 AOE 豁免法术

5. 新增怪物法术
   - 哥布林 B 获得暗影箭戏法

6. UI 更新
   - 单位面板显示施法属性、法术攻击、法术 DC、法术位
   - 技能卡显示法术等级、学派、法术位消耗
   - 战斗日志显示法术位消耗与剩余法术位

## 当前重点系统

- 六项属性：STR / DEX / CON / INT / WIS / CHA
- 职业与等级
- 熟练加值
- 先攻、攻击、豁免基于属性修正
- 技能系统
- 状态系统
- 法术系统雏形
