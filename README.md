# DND HTML5 战棋 Demo v12

本版本跳过 v11，直接实现“职业特性系统”。

## 新增内容

1. 职业/怪物特性数据
   - 新增 `data/classFeatures.json`
   - 单位配置新增 `classFeatures`

2. 战士 Fighter
   - 回气：保留复苏之息治疗
   - 动作如潮：每场战斗 1 次，恢复本回合动作

3. 游侠 Ranger
   - 偏好敌人：对哥布林和兽人攻击伤害 +1
   - 猎人印记：标记敌人，游侠攻击被标记目标时额外 1d6 伤害

4. 哥布林 Goblin
   - 灵巧撤离：获得短暂 AC +2

5. 兽人 Orc
   - 凶蛮重击：重击时额外追加一次武器伤害骰
   - 凶蛮冲锋：获得攻击 +1，持续 2 回合

6. UI 更新
   - 当前单位面板显示职业特性
   - 单位列表显示职业特性
   - 战斗日志显示职业特性造成的额外伤害

## 运行方式

```bash
cd dnd-html5-demo-v12
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```
