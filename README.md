# DND HTML5 战棋 Demo v18

本版本基于 v15，跳过 v16/v17，直接加入数据编辑与调试工具。

## 新增内容

1. Debug 面板
   - 显示当前单位完整战斗状态
   - 显示当前悬停格子的地形、单位和寻路信息
   - 显示当前单位可达格统计

2. 棋盘调试叠层
   - 显示格子坐标
   - 显示地形 ID
   - 显示移动成本
   - 显示当前单位可达格与消耗

3. 简易地图编辑器
   - 勾选“编辑地形”后，点击棋盘即可修改地形
   - 支持普通、障碍、困难、伤害、治疗、目标区域
   - 防止把有单位的格子改成障碍物

4. JSON 导出
   - 可复制当前关卡 JSON
   - 可下载当前关卡 JSON
   - 导出内容包含当前地图 tiles 和单位出生点 spawns

## 运行方式

```bash
cd dnd-html5-demo-v18
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

## 注意

地图编辑是运行时编辑。刷新页面后会恢复原数据。要永久保存，需要把导出的 JSON 合并或替换到 `data/levels.json`。
