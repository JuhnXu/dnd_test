# DND HTML5 Demo v18.2.5

本版重点调整：将“单位编辑器”和“关卡编辑器”拆成两个独立页面。

## 页面

- `index.html`：游玩界面
- `editor.html`：关卡编辑器，只编辑地图、地形、出生点和关卡数据
- `unit-editor.html`：单位编辑器，独立编辑玩家、怪物、NPC 的属性数据

## 新增能力

1. 单位编辑界面独立
   - 可新增、复制、删除单位
   - 可编辑名称、阵营、职业、等级、头像、HP、AC、移动力、熟练加值、六项属性、技能、法术、职业特性
   - 可保存到浏览器 localStorage
   - 可导入/导出 `units.json` 或完整项目数据包

2. 关卡编辑器显示单位数据列表
   - 列表读取当前已编辑的单位数据
   - 点击单位卡片进入放置模式
   - 再点击棋盘即可把该单位作为玩家/敌人出生点添加进场景
   - 右键出生点可删除

3. 游玩界面读取编辑结果
   - 单位编辑器保存后，返回游玩界面即可使用新单位数据
   - 关卡编辑器保存后，游玩界面会按新出生点加载战斗

## 运行

```bash
cd dnd-html5-demo-v18-2-5
python -m http.server 8000
```

然后打开：

- 游玩界面：http://localhost:8000
- 关卡编辑器：http://localhost:8000/editor.html
- 单位编辑器：http://localhost:8000/unit-editor.html

## 注意

编辑结果默认是运行时数据。要让游玩界面读取，请在单位编辑器或关卡编辑器中点击“保存到浏览器”。如果要持久化到项目文件，请导出 JSON 后替换 `data/` 目录中的对应文件。
