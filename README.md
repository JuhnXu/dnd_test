# DND HTML5 战棋 Demo v15

本版本在 v14 的优势/劣势、机会攻击、行动经济、法术与职业特性基础上，加入了关卡与地图系统。

## 新增内容

1. 多关卡数据
   - 新增 `data/levels.json`
   - 每个关卡可配置地图、出生点、参战单位和胜利条件

2. 地形系统
   - 普通地形
   - 障碍物：阻挡移动，提供半掩护
   - 困难地形：移动消耗 2
   - 伤害地形：进入或回合开始受到 1d4 伤害
   - 治疗地形：进入或回合开始恢复 1d4 HP
   - 目标区域：用于撤离/到达类胜利条件

3. 胜利条件
   - 消灭全部敌人
   - 抵达目标区域或消灭全部敌人

4. UI 更新
   - 新增关卡信息面板
   - 新增“下一关”按钮
   - 鼠标悬停格子显示地形说明
   - 地图上用不同颜色和图标显示特殊地形

## 运行方式

```bash
cd dnd-html5-demo-v15
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```
