# DND HTML5 Battle Demo v18.2.6

本版本基于 v18.2.5，主要修复 Token 头像切图问题，并为单位编辑器增加头像库选择。

## 页面入口

- 游玩界面：`http://localhost:8000/`
- 关卡编辑器：`http://localhost:8000/editor.html`
- 单位编辑器：`http://localhost:8000/unit-editor.html`

## 本版更新

1. 重新从原始头像图中居中切割 Token，统一输出为 `256x256` PNG。
2. 修复旧版 `assets/tokens/` 下头像偏移、切歪的问题。
3. 新增更多可用头像资源：战士、精灵、矮人、牧师、卓尔、提夫林、龙裔、半身人、兜帽盗贼、红龙、眼魔、吸血鬼、兽人、骷髅、幽魂、夺心魔、枭熊等。
4. 单位编辑器新增“头像库”，点击头像即可填入头像路径。
5. 保留游玩界面 / 关卡编辑器 / 单位编辑器分离结构。

## 运行方式

```bash
cd dnd-html5-demo-v18-2-6
python -m http.server 8000
```

然后打开浏览器访问上面的页面入口。
